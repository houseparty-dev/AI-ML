Rules to follow throughout your journey
- Practise coding every day you can.
- Spend more time writing code than passively watching tutorials.
- Attempt problems yourself before checking solutions.
- Build projects after learning each major topic.
- Revise old concepts regularly.
- Learn one main programming language first: Python.
- Focus on one deep learning framework first: PyTorch.
- Learn the mathematics alongside machine learning.
- Do not collect certificates without developing practical skills.
- Start building your portfolio before you feel completely ready.
- Apply for opportunities as soon as you have suitable skills and projects.
- Aim for consistent progress, not perfection.

Phase 11: Build your portfolio
Build these projects in increasing difficulty.
- [ ] Project 1: Python calculator, quiz, or expense tracker.
- [ ] Project 2: Data analysis and visualization project.
- [ ] Project 3: Machine learning prediction model.
- [ ] Project 4: Classification project with proper evaluation.
- [ ] Project 5: Deep learning project.
- [ ] Project 6: AI document question-answering application.
- [ ] Project 7: Deployed AI application with an API and database.
IMPORTANT
For every project:
- [ ] Write your own code.
- [ ] Upload it to GitHub.
- [ ] Write a clear README.
- [ ] Explain your approach.
- [ ] Test the application.
- [ ] Document its limitations.
- [ ] Deploy your best projects where practical.
